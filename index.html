Genshin Optimizer

Stores your data in a private (unlisted) GitHub Gist on your own account. Once a token is saved on a device, that device auto-syncs in the background: any change pushes to the cloud a few seconds later, and opening the app pulls down the cloud copy if it's newer than what's local. Create a token at github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, check only the gist scope, then paste it below — once per device. The token is saved only in this browser's local storage and is sent only to api.github.com — it's never included in Export files or committed anywhere. Note: if you edit on two devices before either syncs, whichever pushes last wins (no merge) — use the manual buttons below to force a sync if you want to be sure before switching devices.

Everything is stored locally in this browser (localStorage) — nothing is uploaded anywhere. Stat scoring uses community rule-of-thumb weights, not a full rotation damage simulation. Use Export occasionally to back up your data.
