Genshin Optimizer

Stores your data in a private (unlisted) GitHub Gist on your own account, so you can pull it down on another device. Create a token at github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, check only the gist scope, then paste it below. The token is saved only in this browser's local storage and is sent only to api.github.com — it's never included in Export files or committed anywhere.

Everything is stored locally in this browser (localStorage) — nothing is uploaded anywhere. Stat scoring uses community rule-of-thumb weights, not a full rotation damage simulation. Use Export occasionally to back up your data.
